# Mi proyecto audiovisual con IA (LCA425)

Este repo es tu pieza para el curso LCA425: historia, guion, shotlist, prompts, audio y web.
Aquí vive el texto y los links. El video y el audio viven en tu carpeta de Drive.

## Reglas

Las reglas del curso no están copiadas aquí. Viven en dos lugares:

- El plugin `lca425` de Claude Code. Al inicio de cada clase: `/plugin marketplace update lca425` y luego `/reload-plugins`.
- El estándar del curso: https://github.com/daniknn/lca425-estandar/blob/main/AGENTS.md

Si algo de este archivo choca con el estándar, manda el estándar.

## Cómo empezar

1. Abre Claude Code en esta carpeta y corre `/lca425:brief`.
2. Si no tienes Claude Code, usa la tarjeta `brief` en claude.ai y pega el resultado en `00_brief.md`.
3. Trabaja en una rama, abre un PR y espera el gate en verde.

## Los cuatro niveles

- Libre: mergeas tu PR cuando el gate está en verde.
- Aviso: mergeas con el gate en verde; Daria lo revisa en la clase siguiente.
- Revisión: mergeas con el gate en verde y el reto en frío respondido; Daria califica después.
- Permiso: abres un issue de autorización antes de empezar (solo para temas sensibles, pasarte del tope de créditos o publicar fuera del aula).

## Carpetas

- `00_brief.md`: qué vas a hacer y para quién.
- `01_historia/` a `06_web/`: una carpeta por etapa; cada una explica qué va ahí.

## Lo que no se hace

- Nunca subas video, audio ni archivos de edición al repo: va en tu carpeta de Drive.
- No pongas llaves, contraseñas ni datos de otras personas en ningún archivo.
- Da crédito en tu PR al material que no hiciste (música, imágenes, logos, voces).
- No hagas push directo a `main`: siempre por PR.
- Si algo se bloquea, lee el mensaje completo: dice qué pasó y cómo destrabarlo.
